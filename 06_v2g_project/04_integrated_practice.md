# 06-04. V2G 미니 프로젝트 완성

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 미션: 전기차 1대·4시간의 계획 검토 보고서

앞 교안의 B계획을 따라 계산한 뒤 단가가 바뀌는 상황을 확인합니다. [제공 입력·코드·예상 결과](../examples/v2g/README.md)를 사용하므로 직접 데이터를 만들 필요가 없습니다.

## 기본 경로: 설치 없이 수행

1. 초기24, 용량40, 허용8~36, 최대4, 종료24와 단위를 적습니다.
2. 4행 손계산 표와 에너지 보존식을 작성합니다.
3. A·B계획을 같은 종료 저장량 조건으로 비교합니다.
4. 모든 구간의 전력과 저장량을 검사합니다.
5. 아래 변화 실험을 풀고 결론과 한계를 5문장 이내로 적습니다.

### 변화 실험

마지막 판매 단가만 220→120원/kWh로 바꿉니다. 전력 계획은 그대로 둡니다. 에너지 표는 달라질까요? 거래수지는 얼마일까요?

<details>
<summary>확인 정답</summary>

에너지 표는 그대로이며 판매액은 800+480=1,280원입니다. 구매720원이므로 거래수지는 560원입니다. 기본960원보다 400원 작지만 A의 0원보다는 큽니다. 동일 종료 저장량24는 유지됩니다. 이는 바꾼 가상 단가에 대한 계산 결과이며 현실 수익 예측이 아닙니다.

</details>

## 선택 경로: Python 실행

저장소 전체를 다운로드한 뒤 루트 폴더에서 실행합니다. 코드에는 한국어 주석이 있고 외부 패키지는 필요하지 않습니다.

```text
python examples/v2g/simulate.py
python -m unittest discover -s examples/v2g -p "test_simulate.py" -v
```

스크립트는 [result.csv](../examples/v2g/result.csv)를 입력 파일 옆에 저장합니다. 실행 시 같은 파일을 갱신합니다. 저장된 CSV를 다시 읽어 [expected.csv](../examples/v2g/expected.csv)와 비교하며 저장량·SOC·금액의 일치를 확인합니다. 테스트는 전력·에너지 상하한, 종료 불일치, 잘못된 입력도 검사합니다.

## AI에게 도움을 청하는 연습

```text
위 4시간의 입력과 모델 가정만 사용해 충방전을 설명해 줘.
전력·시간·에너지·금액 단위를 명시하고 손계산식도 보여 줘.
각 구간 제약과 종료24를 확인한 뒤 대기 계획과 비교해 줘.
실제 시장 수익이나 최적 전략이라고 단정하지 마.
```

## 제출물과 완료 조건

제출물은 [공통 기록 양식](../07_safety_evaluation/submission_template.md)에 4행 표, 비교표, 변화 실험, 제약 확인, 실행 여부를 담은 Markdown 한 파일입니다. 손계산 경로도 같은 성취 기준을 사용합니다.

필수 확인: 기본960원·종료24, 변화560원·종료24, 모든 구간 허용 범위, 비용 생략 한계, 실제 실행과 예상 결과 구분. 하나라도 빠지면 보완 후 다음 평가로 이동합니다.
