# 00. AI Agent 학습 시작 안내

## 누구를 위한 과정인가요?

- AI를 처음 활용하는 학생
- 보고서·발표·데이터 정리 등의 업무를 효율화하고 싶은 학습자
- 코딩에 익숙하지 않지만 AI의 도움으로 프로젝트를 시작하려는 학습자

## 준비물

1. 인터넷 접속이 가능한 PC
2. 사용할 수 있는 AI 서비스 계정 (예: ChatGPT)
3. 실습 내용을 기록할 텍스트 편집기 또는 노트

처음에는 Python 및 VS Code 설치가 필요하지 않습니다. 코드 실습 과정에서 별도로 안내합니다. 서비스별 기능과 사용량 제한은 계정에 따라 다를 수 있습니다.

## 첫 실습 (약 10~15분)

AI에게 다음 작업을 요청해 보세요.

```text
역할: 너는 대학생의 학습을 돕는 AI 튜터야.
목표: AI Agent와 일반 챗봇의 차이를 이해하고 싶어.
대상: 프로그래밍을 처음 배우는 대학생.
요청: 차이점 3가지를 일상생활 예시와 함께 설명해 줘.
출력: 비교표 1개와 핵심 요약 3문장.
제약: 어려운 용어는 쉬운 말로 풀어서 설명해 줘.
```

### 결과 검증 질문

- AI Agent가 외부 도구를 사용하는 경우와 단순히 답변만 하는 경우를 구별했나요?
- 설명이 초보자에게 이해하기 쉬웠나요?
- 근거가 필요한 주장은 확인할 수 있나요?

## 학습 기록 템플릿

```text
실습 날짜:
해결하려는 문제:
사용한 프롬프트:
AI가 만든 결과:
확인한 오류 또는 부족한 점:
개선한 프롬프트:
배운 점:
```
