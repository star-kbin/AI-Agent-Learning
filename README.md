# 🤖 AI Agent Learning | AI 에이전트 기초부터 실무 활용까지

> **AI와 함께 일하는 방법을 배우는 실습 중심 학습 저장소**

AI Agent의 기본 개념을 이해하고, 명확한 프롬프트로 업무를 지시하며, 생성된 결과를 직접 검증하는 역량을 기릅니다. 프로그래밍 경험이 없는 학습자도 시작할 수 있습니다.

## 🎯 학습 목표

- LLM, 챗봇, AI Agent의 차이를 설명할 수 있다.
- 목적·맥락·제약·출력 형식을 포함한 프롬프트를 작성할 수 있다.
- 문서 작성, 자료 조사, 데이터 분석, 코딩 업무에 AI를 적절히 활용할 수 있다.
- AI의 잘못된 응답 및 보안 위험을 식별하고 결과를 검증할 수 있다.

## 이 과정에서 함께 쓰는 일상 데이터

**동네 빵가게의 3일 판매 기록**으로 설명과 실습을 이어 갑니다. 준비한 빵, 손님이 주문한 빵, 실제로 판 빵을 비교하고 남은 수량과 매출을 계산합니다. 실제 가게의 영업 자료가 아닌 교육용 가상 데이터입니다.

| 날짜 | 준비 수량(개) | 주문 수량(개) | 판매 수량(개) | 개당 가격(원) |
|---|---:|---:|---:|---:|
| 2026-10-01 | 30 | 25 | 25 | 2,000 |
| 2026-10-02 | 40 | 45 | 40 | 2,000 |
| 2026-10-03 | 30 | 20 | 20 | 2,000 |

**주문 수량**은 손님이 사고 싶다고 요청한 빵의 개수입니다. 준비한 빵보다 주문이 많으면 모두 팔 수 없으므로 **판매 수량**과 다릅니다. 이 예시에서는 다음 날로 재고를 넘기지 않으며 반품·할인은 없습니다.

**확인 정답:** 총 85개 판매, 매출 170,000원, 남은 빵 15개, 채우지 못한 주문 5개. 매출은 판매 금액이며 원가를 빼지 않았으므로 이익이 아닙니다.

[샘플 데이터·용어 풀이·손계산 정답](./examples/bakery_sales/README.md) · [CSV 파일](./examples/bakery_sales/sample.csv)

학습은 **개념 이해 → 프롬프트 작성 → 도구 활용 → 문서·데이터 → 협업 코딩 → V2G → 안전성·평가** 순서로 진행합니다. 04~07 기본 경로는 설치 없이 GitHub 교안·계산기·메모장으로 수행하며 Python 실행은 선택입니다.

### 04~07에서 완성할 결과

| 과정 | 산출물 | 핵심 검증 | 권장 시간 |
|---|---|---|---|
| 04 | 원문 기반 회의록·판매 보고서 | 사실·제안 구분, 수량·매출·누락 확인 | 2.5~4시간 |
| 05 | 작은 코드 수정안·검증표 | 정상·경계·오류 입력, 실행 여부 기록 | 2.5~4시간 |
| 06 | 4시간 충방전표·전략 비교 보고서 | 전력·저장량·SOC·동일 종료 조건 | 2.5~4시간 |
| 07 | 최종 검토표·인계 기록 | 자료·권한·외부 지시·독립 근거 | 2.5~4시간 |

각 과정은 개념 3개 → 통합 실습 → 독립 평가 순서입니다. **연습에는 AI 도움을 사용할 수 있지만, 독립 평가는 AI·자동완성·교안·해설 도움 없이 먼저 답한 뒤 정답을 펼쳐 채점합니다.** 계산기와 빈 메모지는 사용 가능합니다. 5문항×20점=100점이며 80점 이상은 다음 단계, 60~79점은 검증 교안 보완, 0~59점은 첫 교안부터 복습을 권장합니다. 점수는 교육용 자기점검으로 공인 자격을 뜻하지 않습니다.

## ✅ 학습 원칙

1. **문제 정의:** 무엇을, 왜 해야 하는지 분명히 합니다.
2. **작업 지시:** 입력·제약조건·출력 형식을 구체적으로 전달합니다.
3. **결과 검증:** 출처, 숫자, 실행 결과, 오류를 확인합니다.
4. **개선 기록:** 수정 전후 프롬프트와 결과를 비교합니다.
5. **안전한 활용:** 개인정보·API 키·회사 기밀을 무단 업로드하지 않습니다.
