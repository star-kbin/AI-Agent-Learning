# 03-04. Codex를 활용한 안전한 협업 코딩

[← 목차](./README.md) | [다음 →](./05_github_workflow.md)

## 목표
AI 코딩 에이전트에 **작은 변경 작업**을 맡기고 변경 내용을 검증합니다. Codex 이용 가능 여부와 인터페이스는 구독·설정·플랫폼에 따라 다를 수 있습니다.

## 1. 시작하기
- [Codex 공식 문서](https://developers.openai.com/codex/)를 확인합니다.
- 자신의 환경에서 제공되는 Codex 앱·CLI·IDE 확장 또는 클라우드 인터페이스 중 가능한 하나를 선택합니다.
- 프로젝트 폴더 또는 저장소를 연결하기 전 **권한, 파일 접근 범위, 명령 실행 승인 설정**을 확인합니다.
- 별도 설치가 부담스럽다면 **아래 요청 문장 설계만 연습하고 실제 Codex 실습은 선택 과제**로 진행합니다.

## 2. 실습 대상 — 아주 작은 Python 파일
`sum_values.py`:
```python
# 빵가게의 3일 판매 수량(개), 교육용 가상값
sold_quantities = [25, 40, 20]
print(sum(sold_quantities))
```

[공통 기록](../examples/bakery_sales/README.md)의 판매 수량만 꺼낸 작은 예제입니다.

## 3. Codex에 주는 작업 요청
```text
[목표] sum_values.py를 초보자가 이해하기 쉽도록 개선
[입력] 프로젝트의 sum_values.py 파일
[범위] 이 파일만 수정하고 다른 파일은 변경하지 마
[작업] 빵 판매 수량의 합계를 계산하는 함수로 분리하고 한국어 주석을 추가
[제약] 외부 패키지, 네트워크, 삭제 명령 사용 금지
[진행] 우선 수정 계획과 변경할 파일을 보여 주고 승인 전에는 수정하지 마
[검증] 실행이 가능한 환경이면 실행 후 결과를 보고하고,
       실행하지 못했다면 실행 여부를 명확히 알려 줘
[출력] 변경 파일, 주요 변경 사항, 테스트 결과, 남은 위험
```

## 4. 사람이 최종 확인해야 하는 것
1. 변경 전후 파일의 **diff**를 확인합니다.
2. 의도치 않은 삭제·추가 패키지·네트워크 코드가 없는지 살핍니다.
3. Python이 설치되어 있다면 `python sum_values.py`를 실행하고 예상 출력 **85**(판매한 빵 85개)을 확인합니다.
4. 실행 여부를 확인하지 않았다면 '검증 완료'라고 적지 않습니다.

## 5. 문제 발생 시
- 파일이 의도와 다르게 바뀌었다면 변경사항을 검토하고 Git 등으로 복구합니다.
- Codex 접근이 불가능한 경우에도 동일한 요구사항을 일반 ChatGPT에서 코드 제안으로 받아 **수동 검토**할 수 있습니다. 실제 파일 변경은 별개입니다.
- AI가 요청과 무관한 파일까지 수정하려 하면 변경 범위를 다시 제한합니다.

## 학습 질문
Codex가 “테스트 통과”라고 말했다면 무엇을 확인할까요? **테스트 명령, 실제 실행 기록, 실패 여부, 변경 내용**을 확인합니다.
