# 03-06. 통합 실습 — AI와 함께 작은 프로젝트 완성하기

[← 목차](./README.md) | [저장소 첫 화면](../README.md)

## 최종 목표
ChatGPT · VS Code · Codex(선택) · GitHub를 활용해 **가상의 빵가게 판매·재고 기록 미니 프로젝트**를 준비하고, 결과를 검증합니다.

코딩 입문자는 **문서형 과제(A)**, Python 학습자는 **코드형 과제(B)**를 선택합니다.

## 제공할 가상 입력 데이터
`data/sample.csv`:
```csv
날짜,준비수량,주문수량,판매수량,개당가격
2026-10-01,30,25,25,2000
2026-10-02,40,45,40,2000
2026-10-03,30,20,20,2000
```

> 모두 **교육용 가상값**입니다. 수량은 개, 가격·매출은 원입니다. 다음 날로 재고를 넘기지 않고 반품·할인은 없는 것으로 가정합니다.

[CSV 다운로드·열 뜻·계산 정답](../examples/bakery_sales/README.md). 주문 수량은 사고 싶다고 요청한 개수이며 판매 수량과 다를 수 있습니다.

## 과제 A — 코딩 없이 진행
1. ChatGPT에 데이터의 의미와 **3일 판매량·매출 합계**를 요청합니다.
2. 계산 과정과 원자료를 직접 대조합니다. (예상: **85개**, **170,000원**). 남은 빵 **15개**, 못 채운 주문 **5개**도 계산합니다.
3. VS Code 또는 웹 편집기로 `README.md`, `results/review.md`를 작성합니다.
4. GitHub 연습 저장소에 올려 파일 구조와 내용을 확인합니다.
5. 처음 프롬프트와 개선 프롬프트의 차이를 기록합니다.

## 과제 B — 코드형(선택)
1. Codex 또는 ChatGPT에 CSV의 총 판매 수량과 매출을 계산하는 **표준 라이브러리만 이용한 Python 코드**를 제안하도록 요청합니다.
2. 변경 범위를 `calculate.py` 파일 하나로 제한합니다.
3. 예상 출력과 실제 실행 결과를 비교합니다.
4. 코드·테스트 근거·실행 방법을 GitHub에 기록합니다.

[실행 가능한 표준 라이브러리 예제](../examples/bakery_sales/calculate.py)를 참고할 수 있습니다. 직접 만든 코드와 결과를 비교하고, 실행했다면 명령과 출력을 기록하세요.

### 추천 프롬프트
```text
목표: sample.csv의 빵 판매 수량·매출·남은 빵·못 채운 주문 계산
맥락: 프로그래밍 초보자의 교육용 예제
입력: 날짜, 준비수량, 주문수량, 판매수량, 개당가격 열과 위의 가상 3행
제약: 인터넷 연결·외부 패키지 불필요, 제공되지 않은 값 추정 금지
출력: 작업 계획, 코드(선택), 예상 결과, 검증 체크리스트
검증: 판매 85개, 매출 170,000원, 남은 빵 15개, 못 채운 주문 5개와 비교
      매출은 판매수량×개당가격이며 비용을 빼지 않았으므로 이익이라고 부르지 마
```
