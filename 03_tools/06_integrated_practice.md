# 03-06. 통합 실습 — AI와 함께 작은 프로젝트 완성하기

[← 목차](./README.md) | [저장소 첫 화면](../README.md)

## 최종 목표
ChatGPT · VS Code · Codex(선택) · GitHub를 활용해 **가상의 전기차 충전 기록 분석 미니 프로젝트**를 준비하고, 결과를 검증합니다.

코딩 입문자는 **문서형 과제(A)**, Python 학습자는 **코드형 과제(B)**를 선택합니다.

## 제공할 가상 입력 데이터
`data/sample.csv`:
```csv
date,kwh,price_per_kwh
2026-01-01,10,200
2026-01-02,15,220
2026-01-03,5,180
```

> 단가와 수치는 **교육용 가상값**이며 실제 충전요금이나 정산 기준을 의미하지 않습니다.

## 과제 A — 코딩 없이 진행
1. ChatGPT에 데이터의 의미와 **3일 합계 kWh**를 요청합니다.
2. 계산 과정과 원자료를 직접 대조합니다. (예상 합계 **30kWh**)
3. VS Code 또는 웹 편집기로 `README.md`, `results/review.md`를 작성합니다.
4. GitHub 연습 저장소에 올려 파일 구조와 내용을 확인합니다.
5. 처음 프롬프트와 개선 프롬프트의 차이를 기록합니다.

## 과제 B — 코드형(선택)
1. Codex 또는 ChatGPT에 CSV의 총 kWh를 계산하는 **표준 라이브러리만 이용한 Python 코드**를 제안하도록 요청합니다.
2. 변경 범위를 `calculate.py` 파일 하나로 제한합니다.
3. 예상 출력과 실제 실행 결과를 비교합니다.
4. 코드·테스트 근거·실행 방법을 GitHub에 기록합니다.

### 추천 프롬프트
```text
목표: sample.csv의 kwh 합계 계산 방법 안내
맥락: 프로그래밍 초보자의 교육용 예제
입력: date,kwh,price_per_kwh 열과 가상 3행 데이터
제약: 인터넷 연결·외부 패키지 불필요, 제공되지 않은 값 추정 금지
출력: 작업 계획, 코드(선택), 예상 결과, 검증 체크리스트
검증: 손계산 합계 30kWh와 비교하고 실행 여부를 구분
```

## 평가 기준(100점, 교육용 루브릭)
|항목|배점|검증 기준|
|---|---:|---|
|문제 정의와 프롬프트|20|목표·입력·제약·출력이 명확함|
|도구의 적절한 선택|15|각 도구의 역할을 구별함|
|작업 파일 구성|20|README·입력·결과가 정리됨|
|결과 검증|30|30kWh 계산 근거, 실행 유무·오류 기록|
|보안·변경 기록|15|가상 데이터·commit·검토 사항 기록|
|**합계**|**100**||

**학습 완료 기준:** 직접 설명할 수 있는 작업 흐름, 검증 가능한 결과, GitHub 파일 링크를 갖춘 상태입니다. 자가 평가 점수는 공식 자격을 의미하지 않습니다.
