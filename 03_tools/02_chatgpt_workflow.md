## 목표
02과정의 **목표·맥락·입력·제약·출력·검증** 구조를 실무에 적용합니다. 설치 없이 웹에서 실습할 수 있습니다.

## 실습 A: 팀 과제 계획 만들기
아래 프롬프트를 복사하고 괄호 안 내용을 자신의 상황으로 바꿉니다.

```text
[목표] 대학생 3명이 수행할 데이터 분석 과제의 실행 계획 수립
[맥락] 코딩을 처음 배우는 학생, 1주일, 하루 2시간
[입력] 가상의 전기차 충전 기록: date, kwh, price_per_kwh
[제약] 실제 데이터가 없으므로 분석 결과나 수익 수치를 만들지 말 것
[출력] 일정표, 개인별 역할, 산출물, 위험 요소
[검증] 각 산출물의 완료 조건과 확인 방법을 표로 정리
```

### 확인하기
- [ ] 실제 데이터가 없다는 사실을 반영했나요?
- [ ] 역할·산출물·완료 조건이 구체적인가요?
- [ ] 필요 이상으로 어려운 기술을 강요하지 않나요?

## 실습 B: 결과 수정
첫 답변을 보고 다음처럼 요청해 보세요.

```text
방금 제안한 계획에서 초보자가 실행하기 어려운 항목을 3개 찾고,
각 항목을 더 쉬운 과제로 변경해 줘.
변경 전/변경 후/변경 이유를 표로 작성해 줘.
근거가 없는 수치는 삭제해 줘.
```

## 도구·권한 차이
일반 채팅은 텍스트로 계획을 수립하는 데 적합합니다. 일부 환경에서는 파일 작업과 앱 연결이 가능하지만, **기능 사용 가능 여부는 요금제·설정·도구 권한에 따라 다릅니다**. ChatGPT가 답변에 코드를 적었다고 컴퓨터의 파일이 자동 수정되는 것은 아닙니다.
