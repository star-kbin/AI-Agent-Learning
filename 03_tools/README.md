## 한눈에 보는 연결 구조

```text
문제 정의 → ChatGPT(계획·초안)
                ↓
         VS Code(파일·작업공간)
                ↓
         Codex(변경안 작성·검토)
                ↓
         로컬 실행·테스트·사람 검증
                ↓
         GitHub(commit / PR / 공유)
```

**중요:** ChatGPT와 Codex는 도구/계정/설정에 따라 기능이 다르며, 자동으로 서로의 대화·파일을 공유하지 않습니다. Codex가 파일을 읽거나 수정할 때는 허용된 작업공간과 권한을 먼저 확인하세요.

## 학습 원칙
1. 작은 작업부터 시작하고 변경 범위를 지정합니다.
2. AI 제안을 **검토한 후** 파일 저장·명령 실행·게시를 승인합니다.
3. 코드 생성 결과는 실제 실행·테스트로 확인합니다.
4. 공개 GitHub에는 가상 데이터만 올리고 비밀번호·API 키·개인정보는 제외합니다.
5. 학습 내용은 기능이나 구독 플랜 변화에 영향을 받을 수 있으므로 [공식 문서](./01_tool_overview.md#공식-참고-자료)를 확인합니다.
