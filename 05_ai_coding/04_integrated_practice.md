# 05-04. 변경 검토와 통합 실습

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 미션: 주문을 모두 판매한 것으로 처리하는 버그 수정

[오류 코드](./02_read_and_change.md)를 읽고 요구사항 → 최소 수정 → 검증 → 변경 기록 순서로 작업합니다. 정답 코드와 테스트는 제공되지만 먼저 자신의 수정안을 작성하세요.

## 두 가지 학습 경로

| 경로 | 작업 | 제출 근거 |
|---|---|---|
| A: 설치 없이 | 코드 줄을 읽고 수정 전후 값을 표로 추적 | 정상·공급 부족·0 사례의 계산식 |
| B: Python 선택 | 예제 복사본 수정 후 테스트 실행 | 같은 표 + 실행 명령과 실제 결과 |

A경로에서는 테스트를 통과했다고 쓰지 않습니다. B경로에서는 제공된 정답을 실행한 것과 자신이 수정한 코드를 실행한 것을 구별합니다.

## 검토 요청문

```text
이 하루 계산 코드와 요구사항을 비교해 줘.
판매수량과 주문수량의 혼동, 0과 음수 처리, 결과의 단위를 확인해.
문제가 있다면 입력 / 실제 결과 / 기대 결과 / 수정 이유로 설명해.
실행하지 못한 검사는 미실행으로 표시하고 불필요한 파일은 바꾸지 마.
```

## 변경 기록 템플릿

```text
문제: 어떤 입력에서 무엇이 잘못되었는가?
계약: 적용한 판매 규칙과 입력 조건
변경 전후: 바뀐 줄과 이유
회귀 확인: 예전에 맞던 사례가 계속 맞는가?
검증: 입력 / 예상값 / 실제값(또는 미실행) / 판단
도움 사용: AI가 제안한 부분과 내가 확인한 부분
미확인: CSV 파일 처리 등 이번 변경 범위 밖의 사항
```

완료 기준: 세 사례가 맞고, 최소 수정 이유와 미실행 여부를 명확히 기록합니다. 공개 전에는 가상 데이터인지, 비밀정보가 섞였는지, 변경 파일이 요청 범위인지 확인합니다.

## 공식 참고

작업 목표·관련 파일·제약·완료 조건을 제공하고 변경 후 필요한 검사와 리뷰를 수행하는 흐름은 [OpenAI 공식 Codex 활용 안내](https://learn.chatgpt.com/guides/best-practices)의 권장 사항입니다(2026-10-20 확인). 계정별 기능과 화면은 다를 수 있으므로 이 수업은 특정 버튼이나 유료 기능에 의존하지 않습니다.
