# 05-01. 요구사항과 완료 조건

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 목표

“코드 짜 줘”라는 요청을 입력·출력·오류·완료 조건으로 나눕니다. 코드를 실행하지 않아도 예상 결과 표를 작성하는 것이 첫 단계입니다.

## 이번 작업의 계약

기존 [빵가게 계산 코드](../examples/bakery_sales/calculate.py)는 파일을 읽고 합계를 반환합니다. 이번에는 파일 읽기를 떼어 내고 **하루 계산 함수**를 연습합니다. 함수란 입력을 받아 정해진 결과를 돌려주는 작은 작업 묶음입니다.

| 항목 | 요구사항 |
|---|---|
| 입력 | 준비·주문·가격: 각각 0 이상의 정수 |
| 규칙 | 판매=min(준비, 주문), 재고 이월·반품·할인 없음 |
| 출력 | 판매수량, 매출, 남은수량, 못채운주문 |
| 잘못된 입력 | 음수·소수·문자·참/거짓은 ValueError로 거절 |
| 제한 | 표준 Python만 사용, 인터넷·실제 고객 데이터 불필요 |

`ValueError`는 “이 작업이 받을 수 없는 값”을 알리는 오류입니다. `min`은 두 값 중 작은 값을 고릅니다. 참/거짓도 정수처럼 취급될 수 있어 이 실습에서는 명시적으로 제외합니다.

## 코드보다 먼저 쓸 확인표

| 준비·주문·가격 | 예상 판매 | 예상 매출 | 남은 빵 | 못 채운 주문 |
|---|---:|---:|---:|---:|
| 30, 25, 2000 | 25 | 50000 | 5 | 0 |
| 40, 45, 2000 | 40 | 80000 | 0 | 5 |
| 0, 5, 2000 | 0 | 0 | 0 | 5 |

이 표를 직접 설명할 수 있어야 코드를 검증할 수 있습니다.

## 요청문 예시

```text
목표: 빵가게 하루 계산 함수 calculate_day를 만들어 줘.
입력·출력·오류 규칙: [위 계약 붙여 넣기]
범위: daily_sales.py와 그 테스트 파일만 변경해.
계산 함수를 CSV 읽기나 화면 출력과 분리해 줘.
완료: 위 3개 사례와 잘못된 입력을 검사하고 실제 실행 여부를 알려 줘.
변경 전후 차이, 실행 명령, 남은 한계를 설명해 줘.
```

완료 기준: 원본 데이터와 독립적인 예상값을 먼저 남겼고, 정상 입력뿐 아니라 오류 처리도 설명합니다.
