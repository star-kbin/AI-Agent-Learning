# V2G 4시간 미니 예제

[06 과정 목차](../../06_v2g_project/README.md) · [실습 교안](../../06_v2g_project/04_integrated_practice.md) · [홈](../../README.md)

차량1대, 초기24 kWh, 용량40 kWh, 저장량8~36 kWh, 최대4 kW, 종료24 kWh입니다. 각 구간1시간, 충방전 효율100%, 주행0, 구매·판매 단가 동일로 가정합니다. 단가와 모든 조건은 교육용 가상값입니다. 세금·수수료·설비비·배터리 열화비는 제외합니다.

## 필요한 파일

| 파일 | 역할 |
|---|---|
| [sample.csv](./sample.csv) | 준비된 4행 입력, 구간·시간(h)·단가(원/kWh)·전력(kW) |
| [expected.csv](./expected.csv) | 손계산 정답: 에너지(kWh)·SOC(%)·수지(원) |
| [simulate.py](./simulate.py) | 선택 실행 예제, 표준 Python만 사용 |
| [test_simulate.py](./test_simulate.py) | 선택 자동 검사 |
| [result.csv](./result.csv) | 예제를 실제 실행해 저장한 결과, 재실행 시 갱신 |

설치 없이 입력과 정답 표를 읽어도 됩니다. 실행하려면 저장소 전체를 다운로드하고 루트 폴더에서 아래 명령을 사용합니다. 파일 경로는 코드 위치를 기준으로 찾으므로 예제 폴더 안에서 실행해도 됩니다.

```text
python examples/v2g/simulate.py
python -m unittest discover -s examples/v2g -p "test_simulate.py" -v
```

예상 출력:

```text
종료 저장량: 24 kWh
거래수지: 960 원
저장 결과 검증: 일치 (result.csv / expected.csv)
```

`simulate.py`는 입력을 읽고 각 구간의 전력·저장량·종료 목표를 검사합니다. 결과를 저장한 뒤 CSV를 다시 읽어 정답과 비교합니다. 위반한 계획을 자동으로 잘라 맞추지 않고 오류로 알립니다. 결과 숫자를 임의로 고치면 다음 실행에서 다시 생성됩니다.

## 독립 확인

충전8 kWh, 방전8 kWh, 구매720원, 판매1680원, 거래수지960원, 종료24 kWh입니다. 대기 계획의0원과는 초기·종료 저장량이 같아 비교 가능합니다. 방전만 한 계획의2400원은 종료8 kWh이므로 같은 종료 목표24를 충족하지 못합니다.

변화 실험: 마지막 단가만120으로 바꾸면 종료24는 같고 수지는560원입니다. 입력을 바꾼 실험은 별도 복사본에서 수행하세요. 기본 정답을 비교하는 실행부는 기본 입력과 다르면 불일치 오류를 내는 것이 정상입니다. 실험에서는 `simulate` 반환값을 실험 손계산과 비교해야 합니다.

이 예제는 실제 전력 거래나 충전 설비를 제어하지 않습니다. 모든 가능한 계획의 최적성을 증명하는 프로그램도 아닙니다.
