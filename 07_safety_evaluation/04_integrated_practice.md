# 07-04. 최종 검토와 인계 실습

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 미션: 문제가 있는 최종 보고서 검토

04~06 중 자신이 수행한 프로젝트를 검토합니다. 작업물이 없다면 아래 가상 초안을 사용하세요. 연습에는 AI 도움을 사용할 수 있지만 최종 독립 평가와 기록을 구별합니다.

> 3일간 빵가게의 순이익은170,000원이며 다음 달에도 매일40개가 팔린다. V2G 방전 전용 계획은2,400원으로 대기보다 우수하다. 코드는 실행하지 않았지만 모든 테스트를 통과했다. 고객 명단도 공개 저장소에 올리면 재현할 수 있다.

## 검토 순서

1. 주장을 나눕니다: 이익 / 예측 / 전략 비교 / 실행 여부 / 공개 자료.
2. [빵가게 원본](../examples/bakery_sales/README.md), [V2G 비교표](../06_v2g_project/03_strategy_validation.md)와 대조합니다.
3. 문제를 표시합니다: 숫자 오류, 근거 누락, 비교 조건, 안전 문제.
4. 수정안을 만들고 [제출 양식](./submission_template.md)에 원문·근거·변경 이유를 남깁니다.
5. 동료가 재확인할 수 있도록 입력과 실행 여부를 인계합니다.

## 검토 기준과 수정 예시

| 항목 | 검증 기준 | 수정 방향 |
|---|---|---|
| 이익 | 원가·비용 존재 여부 | 매출170,000원, 순이익 미확인 |
| 예측 | 장기 자료·모형 검증 여부 | 3일 결과만으로 장기 예측 불가 |
| V2G 비교 | 최종 저장량 동일 여부 | 방전 전용은 종료8로 목표24 미달 |
| 실행 | 실제 명령·출력 여부 | 미실행, 통과 주장 삭제 |
| 안전 | 실데이터 공개 권한·필요성 | 가상 입력으로 재현 자료 구성 |

완료 조건은 다섯 문제를 모두 찾아 수정하고, 각 수정에 근거를 연결하는 것입니다. 비밀정보 공개 또는 권한 없는 외부 전송 계획이 남아 있다면 점수에 관계없이 공유 전 보완합니다.

## 동료 인계 질문

- 어떤 파일부터 읽으면 같은 결과를 확인할 수 있나요?
- 원본과 실험 변경값을 구별할 수 있나요?
- 실행한 결과와 예상 결과가 나뉘어 있나요?
- 확인하지 못한 항목과 다음 조치가 있나요?

인계 후 최종 평가는 AI 없이 진행하고, 받은 도움은 학습 기록에 별도로 표시합니다.
