# 07-03. 근거로 결과 평가하기

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 목표

문장의 품질을 말투가 아니라 근거로 판단합니다. AI에게 재확인해 같은 답을 받는 것만으로 독립 검증을 대신하지 않습니다.

## 주장별로 다른 증거 사용하기

| 주장 | 필요한 근거 | 부족한 근거 |
|---|---|---|
| 빵 매출170,000원 | 원본 수량×가격 계산 | AI가 두 번 같은 숫자를 말함 |
| 코드가 실행됨 | 실행 명령·실제 출력·환경 기록 | 코드 블록이 제공됨 |
| 모든 입력에 안전함 | 명시한 범위와 경계·오류 사례 검사 | 정상 입력 한 번 통과 |
| V2G B가 A보다 거래수지960원 큼 | 동일 초기·종료24, 단가·기간, 수지 계산 | B의 판매액만 비교 |
| 도구 기능을 현재 쓸 수 있음 | 공식 문서와 해당 계정에서 확인 | 날짜 없는 후기 |

## 검증 기록 연습

```text
주장:
근거 파일·원문 구절 또는 공식 링크:
확인 날짜 / 사용한 입력:
계산식 또는 실행 명령:
확인 결과: 일치 / 불일치 / 미확인
수정한 문장:
남은 한계:
```

“미확인”은 실패를 숨기는 표현이 아니라 필요한 다음 행동을 정하는 표시입니다. 출처가 없으면 그럴듯한 링크를 만들어 채우지 않습니다.

## 세 문장 고치기

1. “테스트는 안 했지만 모든 오류가 없다.”
2. “방전만 하면 2,400원으로 최적이다.”
3. “3일 매출이 170,000원이므로 순이익도 같다.”

<details>
<summary>수정 예시</summary>

1. 코드를 작성했으나 미실행이다. 정상·경계·오류 입력 검증이 필요하다.
2. 방전만 한 계획은 종료8 kWh로 목표24에 미달한다. 같은 종료 조건 비교를 통과하지 못하며 최적성도 검증하지 않았다.
3. 매출은170,000원이다. 원가·비용이 제공되지 않아 순이익은 알 수 없다.

</details>

완료 기준: 세 문장을 증거에 맞게 수정하고, 원본 대조·실행·공식 출처 중 어떤 검증이 필요한지 고릅니다.
