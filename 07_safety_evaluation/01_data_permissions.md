# 07-01. 데이터와 작업 권한

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 목표

작업에 필요한 최소 자료와 권한을 고릅니다. “AI가 할 수 있는가”와 “이 업무에서 맡겨도 되는가”는 별도로 판단합니다.

## 자료를 보내기 전 세 질문

1. 업무 수행에 꼭 필요한가?
2. 이 서비스에 제공할 권한과 조직 기준을 확인했는가?
3. 가상 자료나 집계 자료로 목적을 달성할 수 있는가?

이 수업은 가상 자료만 사용합니다. 이름만 지웠더라도 주소·날짜·거래 내역의 조합으로 사람을 알아볼 수 있으므로 충분한 익명화라고 단정하지 않습니다.

## 분류 연습

| 자료·작업 | 수업에서의 선택 | 이유 |
|---|---|---|
| 제공된 가상 빵가게 3행 | 사용 | 실제 고객 정보가 없음 |
| 실제 고객명·전화번호·구매 내역 | 가상 자료로 대체 | 수업 목적에 필요하지 않음 |
| API 키·비밀번호 | 입력·공개 제외 | 접근 권한을 주는 비밀정보 |
| 저장소의 실습 복사본 수정 | 변경 범위를 정하고 검토 | 원본 보존과 변경 추적 |
| 결과를 고객에게 이메일 발송 | 초안과 수신자·내용 검토 후 권한 있는 사람 결정 | 외부에 영향을 주는 작업 |

## 권한을 작게 주는 요청문

```text
제공된 가상 입력만 읽고 보고서 초안을 만들어 줘.
변경은 실습 복사본의 report.md에 한정해.
삭제·외부 전송·공개 게시가 필요하면 작업 이유와 대상을 먼저 보여 줘.
```

## 실수했을 때 연습

연습 상황: 비밀정보를 공개 저장소에 올린 것을 발견했습니다. 실제 키는 사용하지 않습니다. 공개 링크 공유를 중단하고 담당자에게 알리며, 노출된 키의 폐기·재발급과 접근 기록 확인을 진행하도록 요청합니다. 파일 삭제만으로 이전 기록이나 복제본까지 사라졌다고 생각하지 않습니다. 조직의 대응 절차를 따릅니다.

완료 기준: 사용 가능한 가상 자료, 제외할 비밀정보, 별도 검토할 외부 행동을 구분하고 자신의 작업 범위를 한 문장으로 적습니다.
