# 07. 안전성·결과 평가

[← 이전 과정](../06_v2g_project/README.md) · [저장소 홈](../README.md) · [학습 경로 다시 선택](../00_getting_started/README.md)

## 학습 목표

데이터·권한·외부 지시·검증 근거를 확인하고 공유할 결과를 판단합니다.

## 대상·준비·진행 방법

00~03을 읽은 입문자 대상입니다. 기본 경로는 GitHub 교안·메모장·계산기만 사용하며 설치와 유료 기능은 필요하지 않습니다. 연습은 AI 사용 가능, 독립 평가는 AI·자동완성·해설 도움 없이 먼저 답합니다.

권장 시간: 약 2.5~4시간. 숫자는 교육용 가상값이며 실제 업무 자료로 대체하지 않습니다. 코드가 있는 과정에서도 읽기·손계산 경로로 완료할 수 있습니다.

## 학습 완료 기준

1. 통합 실습의 필수 검증 항목을 모두 확인합니다.
2. 최초 답과 수정 이유, 직접 확인한 근거를 남깁니다.
3. 독립 평가 80점 이상을 권장합니다. 점수별 복습 안내는 마지막 교안에서 확인합니다.

점수는 학습 방향을 정하기 위한 자기점검이며 표준화 시험·자격 인증이 아닙니다. 본인이 답한 뒤 정답을 펼쳐 채점하고, 미실행 코드는 실행한 것으로 표시하지 않습니다.
