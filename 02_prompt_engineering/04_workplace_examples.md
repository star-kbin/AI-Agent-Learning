# 02-04. 업무별 프롬프트 실전 예제

[← 목차](./README.md) · [다음: 최종 실습·평가 →](./05_practice_and_assessment.md)

## 학습 목표 (40~60분)
다음 4가지 업무 중 **두 가지를 골라** 프롬프트를 직접 수정하고 결과를 검증합니다.

## 사례 A — 보고서 초안
```text
너는 교육 운영 담당자의 문서 작성을 돕는 조력자야.
[목표] 일주일간의 교육 운영 요약 보고서 초안을 작성해 줘.
[입력] 진행 수업: 파이썬 조건문, 반복문 / 실습 제출: 24명 중 20명 / 질문: 반복문에서 오류가 많았음
[출력] 진행 현황, 학습 성취, 개선 과제의 3개 소제목으로 나눠 줘.
[제약] 제공한 자료 외 성과를 만들어내지 마. 과도한 홍보 표현 금지.
[검증] '확인된 사실'과 '제안'을 구분해 표시해 줘.
```

## 사례 B — 발표자료 기획
```text
[목표] 대학생 대상 'V2G란 무엇인가?' 발표자료 목차 작성
[맥락] 비전공자 대상 10분 발표
[입력] V2G는 전기차 배터리에서 전력망으로 전력을 보내는 개념임
[제약] 실시간 전력 단가나 수익률을 사실처럼 만들어내지 말 것
[출력] 6장 슬라이드별 제목, 핵심 메시지, 추천 그림 설명
[검증] 확인이 필요한 기술·정책 내용은 별도 표시
```

## 사례 C — 데이터 분석 계획
```text
[목표] 센서 데이터 품질 분석 계획 수립
[입력] 열: timestamp, temp, pressure, defect_flag / 샘플 데이터는 아직 없음
[맥락] 제조 데이터 분석을 처음 배우는 학생
[제약] 실제 결측률이나 예측 정확도를 만들어내지 마
[출력] 데이터 이해 → 결측치 → 이상치 → 시각화 → 결과 정리 순서의 체크리스트
[검증] 각 단계에서 확인할 지표와 예상 위험을 알려 줘
```

## 사례 D — 코딩 도움 (코딩 경험 없어도 가능)
```text
[목표] CSV의 월별 평균을 계산하는 파이썬 예제를 설명해 줘.
[맥락] 파이썬을 처음 배우는 대학생
[입력] 열 이름: month, value / 실제 데이터는 미제공
[제약] 예제 데이터는 가상 데이터라고 명시하고, 파일이 없으면 실행 불가한 점을 설명
[출력] 주석 있는 코드, 줄별 설명, 실행 전에 확인할 사항, 예상 출력
[검증] 코드 실행을 수행하지 않았다면 '실행 미검증' 표시
```

## 결과 검증 방법
|영역|반드시 직접 확인할 것|
|---|---|
|보고서|실제 활동·숫자·근거 대조|
|발표자료|기술 개념·최신 제도·그림 설명의 정확성|
|데이터|데이터 존재 여부, 입력 열·단위, 분석 방법의 적합성|
|코드|실행 환경, 패키지, 오류 처리, 실제 실행 결과|

> 개인 정보·회사 기밀·API 키를 AI 서비스에 무단 입력하지 마세요. 외부 자료를 그대로 지시문으로 믿는 프롬프트 인젝션에도 주의하세요.

## 실습 제출물
선택한 업무마다 **최초 요청 / 수정한 요청 / AI 결과 요약 / 검증한 내용 2개 / 개선할 점 1개**를 기록합니다.
