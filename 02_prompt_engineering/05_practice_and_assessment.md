# 02-05. 실습 과제와 학습 성취도 평가

[← 목차](./README.md) · [저장소 첫 화면](../README.md)

## 목표 (30~40분)
프롬프트를 **직접 설계하고 결과를 검증·개선**할 수 있는지 확인합니다.

## 과제 1 — 모호한 요청 개선 (30점)
아래 요청을 6요소를 활용해 다시 작성합니다.

> "우리 빵가게 판매 보고서 만들어 줘."

- 대상 독자와 목적을 직접 설정하세요.
- [3일 가상 기록](../examples/bakery_sales/README.md)을 쓰거나, 자료가 없다면 **추가로 필요한 자료**를 명시하세요.
- 출력 형식·분량·검증 방법을 포함하세요.

## 과제 2 — 업무 실습 (40점)
[실전 예제](./04_workplace_examples.md)에서 1개를 선택하고 직접 프롬프트를 설계해 AI에게 요청합니다.

제출 항목: 최초 프롬프트 / 개선 프롬프트 / 결과 요약 / 수정 이유 / 근거 검증 2건(예: 판매 합계 85개, 매출 170,000원).

## 과제 3 — 결과 검증 (30점)
AI 답변에서 **틀릴 가능성이 있는 항목 3개**를 찾아서 다음을 작성합니다.

1. 검증 대상 문장
2. 확인할 자료나 방법
3. 확인 결과 또는 '미확인' 표시
4. 수정이 필요한 경우 수정 방향

## 평가 기준 (자가 평가 또는 동료 평가용)
|기준|배점|확인 항목|
|---|---:|---|
|목표·맥락의 명확성|20|누가 무엇을 왜 하는지 알 수 있다|
|입력 자료·제약 정의|20|자료 범위, 사실·추정 구분, 안전 기준|
|출력 형식 구체성|20|항목·분량·표·구조 등을 명시|
|검증의 타당성|25|출처·수치·실행·누락을 실제로 확인|
|개선 및 기록|15|수정 전후 비교와 근거를 기록|
|**합계**|**100**||

## 자기 점검
- [ ] AI에 전달한 목표가 구체적이다.
- [ ] 실제 자료와 가정을 구별했다.
- [ ] 원하는 출력 구조를 명시했다.
- [ ] 사실과 수치를 원본 또는 검증 가능한 자료로 확인했다.
- [ ] 결과의 부족한 점을 기록하고 수정했다.
- [ ] 민감 정보나 허가받지 않은 데이터를 넣지 않았다.

## 성취 수준 (운영용 제안)
- **90~100점:** 실무 응용 준비 — 복수 업무에 재사용할 템플릿 제작
- **75~89점:** 기본 활용 가능 — 검증 체크리스트 강화
- **60~74점:** 보완 필요 — 6요소 구조로 재작성 연습
- **0~59점:** 개념 재학습 — [01 프롬프트의 이해](./01_prompt_basics.md)부터 복습

> 이는 교육용 평가 루브릭이며 표준화된 시험이나 자격 인증이 아닙니다. AI가 작성해 준 평가 자체만으로 독립적인 역량을 판정하지 마세요.

## 개인 학습 기록 템플릿
```text
학습 날짜:
선택 과제:
최초 프롬프트:
부족했던 점:
개선 프롬프트:
검증한 항목과 근거:
자기 평가 점수와 이유:
다음에 개선할 행동:
```
