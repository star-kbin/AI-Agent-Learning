# 02. 프롬프트 엔지니어링 — AI에게 일을 정확히 요청하는 방법

[← 01. AI Agent 기본 개념](../01_agent_concepts/README.md) | [← 저장소 홈](../README.md)

프롬프트 엔지니어링은 AI에 명령을 길게 적는 기술이 아니라, **목표를 분명히 하고 결과를 검증할 수 있게 작업을 설계하는 기술**입니다. 코딩 경험이 없어도 시작할 수 있습니다.

## 학습 대상과 준비
- 대상: AI로 생활 기록과 업무를 정리하려는 일반 사용자·학생
- 준비: AI 서비스 접속(예: ChatGPT), 메모장; **Python·VS Code 설치 불필요**
- 권장 학습 시간: 총 약 **2.5~3.5시간**
- 학습 순서: 개념 → 구조 → 개선 → 업무 실습 → 평가

공통 예시는 **빵가게 3일 판매 기록**입니다. [샘플 데이터·쉬운 용어·손계산 정답](../examples/bakery_sales/README.md)을 함께 봅니다.

## 꼭 기억할 프롬프트 구조
```text
목표: AI가 완료할 작업
맥락: 누가 왜 사용하는지
입력: 실제 제공하는 정보
제약: 금지 사항과 지킬 조건
출력: 결과의 형태·길이·필수 항목
검증: 사실·숫자·출처·실행 확인 기준
```

## 학습 완료 기준
1. 모호한 요청을 6요소로 개선할 수 있다.
2. 동일한 업무에서 프롬프트 수정 전후 결과를 비교할 수 있다.
3. AI 출력의 사실·수치·보안 위험을 검토할 수 있다.
4. 보고서, 발표자료, 데이터 분석 또는 코딩 업무의 프롬프트를 작성한다.

## 사용 원칙
AI 응답을 무조건 신뢰하지 마세요. 검증이 필요할 때는 신뢰할 수 있는 출처·원본 데이터·실제 실행 결과를 확인합니다. 타인의 개인정보와 조직의 기밀을 무단 입력하지 않습니다.
