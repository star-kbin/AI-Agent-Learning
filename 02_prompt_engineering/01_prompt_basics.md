# 02-01. 프롬프트 엔지니어링의 이해

[← 목차](./README.md) · [다음: 프롬프트의 6요소 →](./02_six_elements.md)

## 학습 목표 (20~30분)
- 프롬프트와 프롬프트 엔지니어링을 설명한다.
- 모호한 지시와 명확한 지시의 차이를 확인한다.
- AI가 제공한 결과가 곧 정답은 아님을 이해한다.

## 1. 프롬프트란?
프롬프트(Prompt)는 AI에게 전달하는 질문·자료·작업 지시입니다. 프롬프트 엔지니어링은 **목적에 맞는 입력을 설계하고 출력 결과를 평가·개선하는 과정**입니다. 마법 같은 문장보다 명확한 목표, 관련 정보, 검증 기준이 중요합니다.

> AI Agent에서는 프롬프트가 '무엇을 해야 하는지' 지시하지만, 도구 접근·실행 권한·파일 수정 같은 실제 행동은 시스템과 사용자가 허용한 범위에서만 가능합니다.

## 2. 좋지 않은 요청과 개선된 요청

**모호한 요청**
```text
AI에 대해 발표자료 만들어 줘.
```
문제점: 청중·목적·분량·결과 형식이 정해지지 않았습니다.

**개선된 요청**
```text
대상: AI를 처음 배우는 대학생 20명
목표: AI Agent와 일반 챗봇의 차이 설명
자료: 아래 수업 개요만 활용
산출물: 5장 발표자료의 슬라이드별 제목과 핵심 문장
제약: 슬라이드마다 3개 항목 이하, 어려운 말은 괄호로 풀이
검증: 불확실한 기술 설명은 '확인 필요' 표시
수업 개요: [직접 입력]
```
개선 이유: 같은 자료를 활용해 **관찰 가능하고 평가 가능한 출력**을 요청합니다.

## 3. 핵심 원칙
1. **명확성:** 목표와 대상이 누구인지 쓰기
2. **충분한 맥락:** 필요한 배경·입력 자료 제공
3. **관찰 가능한 형식:** 표·목차·항목 수·파일명 등 지정
4. **검증 가능성:** 수치·출처·누락을 확인할 방법 마련
5. **반복 개선:** 결과를 보고 프롬프트 한 부분씩 수정

## 4. 주의할 점
- AI는 자신감 있게 틀린 답을 만들 수 있습니다.
- '전문가처럼'이라는 역할 지정만으로 사실성이 보장되지 않습니다.
- 회사 기밀·주민등록번호·비밀번호·API 키를 붙여 넣지 않습니다.
- AI가 브라우징 또는 파일 작업을 실제로 수행했는지 **도구 실행 결과**로 확인합니다.
- 중요한 사실·계산·코드는 원자료 또는 실행으로 별도 검증합니다.

## 실습
'취업 준비 방법 알려줘'를 **대상, 기간, 결과 형식, 제약 조건**이 포함된 요청으로 고쳐 AI에 입력해 보세요. 두 응답을 비교하여 더 구체적인 답변이 나온 이유를 3문장으로 기록합니다.
