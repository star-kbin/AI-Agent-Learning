# 04-01. 자료에서 문서 초안 만들기

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 목표

원문에서 확인한 사실과 AI가 제안한 내용을 나누어 문서 초안을 만듭니다. 02과정의 6요소 프롬프트, 03과정의 파일 확인 방법을 사용합니다.

## 먼저 읽을 가상 원문

> 2026-10-04 빵가게 회의 메모. 참석자는 점장과 직원 1명이다. 3일간 판매량은 85개였다. 둘째 날 주문 5개를 채우지 못했다. 다음 주 금요일에 준비 수량을 검토하기로 했다. 할인 행사는 아이디어만 나왔고 시행 여부는 정하지 않았다. 검토 담당자는 아직 정하지 않았다.

이 원문은 이 수업에서 만든 가상 자료입니다. 다른 회의 기록이나 실제 고객 정보는 입력하지 않습니다.

## 따라 하기

1. 날짜, 참석자, 결정, 미결정을 각기 밑줄로 표시합니다.
2. 아래 요청문으로 초안을 받거나, AI 없이 직접 표를 작성합니다.
3. 원문과 초안을 한 문장씩 대조합니다. 잘못된 담당자나 결정이 추가되면 고칩니다.

```text
목표: 아래 가상 회의 메모를 점장이 읽을 회의록으로 정리해 줘.
입력: [위 원문을 여기에 붙여 넣기]
제약: 원문에 없는 담당자·날짜·결정을 만들지 마.
      '다음 주 금요일'은 원문 표현 그대로 두고 정확한 날짜는 확인 필요로 표시해.
출력: 사실 / 결정 / 미결정 / 후속 확인 표와 3문장 요약.
검증: 할인은 미결정이고 담당자는 미정인지 원문 구절과 대조해.
```

## 확인 예시

| 구분 | 기록 | 근거 |
|---|---|---|
| 사실 | 판매 85개, 둘째 날 미충족 주문 5개 | 원문의 수치 |
| 결정 | 다음 주 금요일 준비 수량 검토 | '검토하기로 했다' |
| 미결정 | 할인 시행 여부, 검토 담당자 | '정하지 않았다' |
| 후속 확인 | 검토 날짜·담당자 확정 요청 | 원문에 없는 정보임을 표시한 제안 |

요약 예시: 3일간 85개를 판매했고 둘째 날 주문 5개를 채우지 못했다. 다음 주 금요일 준비 수량을 검토하기로 했다. 할인 시행과 검토 담당자는 미정이며 정확한 검토 날짜를 확인해야 한다.

## 직접 해보기

잘못된 초안인 “직원이 다음 주 금요일부터 10% 할인을 시행한다”를 원문에 맞게 고치세요. **담당자·시행·할인율** 세 부분의 근거가 있는지 각각 적습니다.

완료 기준: 미결정 두 가지를 보존하고, 제안은 결정과 다른 칸에 적었습니다. 문장이 유창한 것만으로 통과시키지 않습니다.
