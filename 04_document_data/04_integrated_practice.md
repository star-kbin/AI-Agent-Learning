# 04-04. 문서·데이터 통합 실습

[과정 목차](./README.md) · [저장소 홈](../README.md)

## 미션: 점장이 내일 읽을 1쪽 보고서

입력은 [3일 판매 기록](../examples/bakery_sales/README.md)과 [회의 메모](./01_document_workflow.md)뿐입니다. 새로운 자료 수집이나 프로그램 설치는 필요하지 않습니다.

## 진행 순서

1. 보고서를 읽을 사람과 결정할 일을 적습니다: “점장이 준비 수량 검토 회의를 준비한다.”
2. 원본의 기간·단위·가정과 품질 점검 결과를 적습니다.
3. 02과정의 6요소로 요청문을 작성합니다. AI 사용은 연습 단계에서 허용합니다.
4. 판매·매출·남은 빵·미충족 주문을 손계산합니다.
5. 초안에서 원가 없는 이익, 근거 없는 미래 예측, 미정인 담당자를 찾습니다.
6. 아래 템플릿으로 수정본을 남깁니다. AI 계정이 없으면 [이전 교안의 잘못된 보고](./03_analysis_report.md)를 초안으로 사용합니다.

## 제출 템플릿

```text
제목 / 독자 / 목적:
입력: 파일명, 기간, 단위, 가정
품질 확인: 행 수, 중복, 누락, 수량 관계
최초 요청문:
초안에서 발견한 오류와 원문 근거:
개선 요청문:
최종 보고: 사실 3개 / 한계 2개 / 제안 1개
계산 확인: 판매 / 매출 / 남은 빵 / 미충족 주문
실행 여부: 손계산만 / 코드 실행(명령·실제 출력)
다음에 확인할 자료:
```

## 제출 전 검증 기준

- [ ] 원본 3행을 썼으며 오류 연습 표를 원본으로 착각하지 않았다.
- [ ] 85개, 170,000원, 15개, 5개와 계산식이 있다.
- [ ] 준비=판매+남은 빵, 주문=판매+미충족 주문이 맞는다.
- [ ] 할인 시행과 담당자는 미정이라고 기록했다.
- [ ] 이익·장기 예측을 단정하지 않고 확인할 자료를 적었다.

통과 조건: 다섯 항목 모두 충족. 부족한 항목은 관련 교안으로 돌아가 고친 뒤 재확인합니다. 다음 평가에서는 AI의 도움 없이 새로운 답안을 작성합니다.
